One word, first thought: `galumph`. The field is full of solemn, Latinate nature nouns — petrichor ten times over, defenestration seven, apricity, psithurism — so this entry plays a different card: a verb, short and funny-sounding, that moves. Lewis Carroll's portmanteau of gallop and triumph, for lumbering along in gleeful, clumsy victory. Surprising because nobody guesses a nonsense verb, vivid because you can see the heavy happy bounce in seven letters, witty twice over in its sound and its double meaning. The program scores a shortlist of candidates against the rubric's criteria in their published order and writes the winner to `/output/entry.txt`, where a judge model compares it two at a time against the other entries.

## Run it

```sh
node main.ts
```

`main.ts` runs on Node 22 and writes `galumph` (7 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Standard library only, no network, no secrets, fully deterministic.
